Idleon Toolbox coverage gaps

Original audit snapshot of what Idleon Toolbox covers that Idleon Efficiency lacks.

Basic displays now cover Bribes, Guild bonuses, Advice Fish, Event Shop bonuses, and Armor Smithy. They also cover Zenith Market, The Button, and permanent bonuses from Owl, Kangaroo, and Bubba. They use compact cards, shared summaries, and applicable filters. Feature-owned core tests compare representative calculations or ownership states with game results. The gap list preserves the original findings, including aspects outside these basic displays.

Zenith Market shows total owned Zenith Clusters across the wallet, bags, and storage, with a tooltip breakdown by location. It shows each upgrade's next-level cost and cost to max, coloring each green when total owned clusters cover the cost. Each clicker groups its balance, next permanent upgrade cost, and next bonus, with true currency icons and transparent bonus art. Owl values use raw game formatting; Roo uses CommaNotation above 100 and one decimal at or below 100. Bubba aggregate values use full-number formatting; the game source does not establish a matching aggregate-row formatter. The Button shows representative bonus icons, its next bonus, and three upcoming tasks with progress. Character tasks use the character with the most progress. Progress handlers cover all 57 saved tasks, including maximum damage for task 49. Spelunking power uses persistent saved state only; Elixir progress remains limited by runtime data. Real-save smoke confirmed all 57 tasks return available finite progress; all 11 character maxima are finite, and task 49 matches native maximum damage for Sludgev4 (4.975258141047525e28).

Inactive cards use 50% opacity, matching existing collection and locked-upgrade displays. Owned or upgraded entries remain at full opacity. Advice Fish artwork uses seven cropped regions from the existing game UI atlas.
