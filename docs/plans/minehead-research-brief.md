### Game mechanic and source evidence

Current source is local Idleon 1.23, “Luminous_Menagerie”, captured in [`Minehead.1.23.js`](../game-snippets/minehead/Minehead.1.23.js). - **Allowance:** `_customBlock_Minehead("DailyTries",0,0)` returns `round(3 + ResearchStuff("Grid_Bonus",147,1))` (snippet line 8; source `idleon1.23.txt:244133`). Mode 1 returns the rounded account Research grid level `Research[0][147]`, not a character Research skill or mode-0 bonus (`idleon1.23.txt:243984-243987`; domain API `data/domain/world-7/research.tsx:1004-1018`). Unit is attempts per daily cycle.
- **Saved remaining state:** raw save key `Research[7][8]` is part of the non-player `Research` array; repository maps it account-wide, not per character (`data/domain/world-7/minehead.tsx:90-95`; `data/domain/base/domain.tsx:48-62`). It is a count of available attempts: native UI enables the start control only when this value is at least 1 and displays the stored count or “None!” (`idleon1.23.txt:287727-287736,287858-287863`).
- **Consumption:** Starting a game decrements `Research[7][8]` by one only when the value is at least 1 (`idleon1.23.txt:288299-288301`). This makes the numerator remaining attempts, rather than attempts already used.
- **Victory restoration:** On victory, source increments the count by one and caps it at the current `DailyTries` allowance (`idleon1.23.txt:294862-294863`). A win therefore restores the consumed attempt, up to allowance; a failed/lost game does not pass through this victory increment in the inspected path. This is native game bookkeeping, not a website-derived rule.
- **Allowance change / overflow:** The allowance is calculated separately from the saved remaining count. Increasing Research grid level can raise the denominator without immediately raising the saved numerator; the victory path applies an upper cap, but no source evidence supports clamping arbitrary saved state for website display. Preserve source values; do not force remaining ≤ allowance.
- **Daily reset:** A reset handler assigns `Research[7][8] = round(DailyTries)` (`idleon1.23.txt:322198`). This establishes the reset value, not when or how frequently this handler runs. Reset timing remains unknown and is not required to display current saved state.
- **Native presentation:** Native Minehead UI shows a numeric available count and start-button availability; it does not show a remaining/allowance ratio in the inspected lines (`idleon1.23.txt:287727-287736,287858-287863`). The ratio is the requested website improvement, not a claim of native UI parity.
